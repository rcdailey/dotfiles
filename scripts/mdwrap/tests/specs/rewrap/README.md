# Vendored Rewrap specs

Source: <https://github.com/dnut/Rewrap>, commit `158709d3780d0cfc04fe00dcebfbb590ce8c29e1`.
Files come from `docs/specs/content-types/markdown/` and `docs/specs/features/` (prefixed
`feature-`). They are licensed under Apache-2.0 (see `LICENSE`).

The files are renamed to `.txt` so Markdown formatters do not change them. Examples that mdwrap
handles differently are modified; each modified example is preceded by a paragraph that starts
with `mdwrap deviation:` and states the upstream behavior and the reason for the change.
